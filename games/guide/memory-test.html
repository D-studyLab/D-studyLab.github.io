記憶力テスト

記憶・診断・所要 約3分・ブラウザで無料・インストール不要
▶ 記憶力テスト を遊ぶ

ルール

AIやテンプレの話ではなく、あなたの記憶そのものを測るテストです。課題は3つ。順唱は数字が1つずつ出るので出た順に答えます。逆唱は同じように出ますが逆から答えます。場所はマスが順に光るので同じ順にタップします。心理学で使われる数唱スパンと Corsi ブロック課題がもとになっています。

攻略のコツ

10問固定ではありません。正解するたびに1つ長くなり、まちがえると1つ短くなります。続けて2回まちがえるか、9問終わるとその課題は終わりです。だから誰でも必ず最後はまちがえます。そこがあなたの限界で、それを測るのが目的です。コツは、数字を「音」で覚えること。3桁ずつ区切って口の中で繰り返すと逆唱が伸びます。場所の課題は逆に、指でなぞる動きとして覚えるほうが残ります。

この作品を作った理由

「記憶力がいい」という言葉は曖昧すぎると思ったのが出発点です。実際に測ると、覚える力と、頭の中で並べ替える力は別物だとわかります。順唱は高いのに逆唱だけ落ちる人がいて、その人は買い物メモを見ずに回るのが苦手だったりする。3つに分けたのはそのためです。

技術的な仕掛け

偏差値は「順唱7・逆唱5・場所5」を50に置いた、このテスト独自の擬似値です（全国調査ではありません。画面にも明記しています）。順唱の目安7±2は Miller (1956) の古典的な指摘によります。逆唱はワーキングメモリの中核なので重み1.4で重く見ています。純ロジック層を分けてあり、階段法が「必ず終わる」ことをテスト32件で検査しています——作った直後は、正解し続けると永久に終わらないバグがありました。

3つの課題と、その元ネタ

測るのは3つです。① 順唱——数字が1つずつ出るので、出た順に答えます（心理学でいう数唱スパン／forward digit span）。② 逆唱——同じように出た数字を逆から答えます（逆唱スパン。ワーキングメモリの中核とされる課題）。③ 場所——マスが順に光るので、同じ順にタップします（Corsiブロック課題、視空間スパン）。

10問固定ではなく「階段法」で測る

このテストは問題数が決まっていません。長さ3から始めて、正解したら1つ長く、間違えたら1つ短く。そして同じ長さで2回落ちたらその課題は終了します。つまり誰でも必ず最後は間違える設計で、そこがその人の限界というわけです。「全問正解して終わる」ことはありません。

ひとつ実装上の注意として、1課題あたり9回の上限を入れてあります。これが無いと、メモを取るなどして正解し続けるかぎり永久に終わりません。実装当初これに気づかず、ブラウザで自動プレイさせて発覚しました。

偏差値はどう出しているか

素点は 順唱×1.0 ＋ 逆唱×1.4 ＋ 場所×1.2。逆唱を重く見ています。基準は「順唱7・逆唱5・場所5」を偏差値50に置きました。順唱7±2 は Miller (1956) の古典的な指摘で、逆唱5前後・視空間5前後は一般的に言われる目安です。上下は25〜80で頭打ちにしてあります。

ただし、これは全国調査による数値ではなく、あくまでこのテストの採点モデルによる擬似値です（画面にも明記しています）。

結果から返す「弱点の読み方」

3課題の偏りを見て、次のような指摘を返します。順唱は高いのに逆唱が3以上低いなら、覚える力よりも「頭の中で並べ替える力」のほうが弱い。場所だけ2以上高いなら、場所法（覚えたいものを部屋の風景に置く記憶術）が向いている。言語系だけ2以上高いなら、図で覚えるより声に出すほうが残るタイプ、という具合です。

数字の裏づけ

memory.test.js の32件で、決定論・出題の性質・逆唱の正解・階段法・偏差値・称号を検査しています。階段法については特に「正解し続けても必ず終わる」「正解と誤答が混ざっても必ず終わる」「上限・下限を割らない」「元の状態を書き換えない」を確認しています。

three.jsのような外部ライブラリは使っていません（数字とマスを表示するだけなので不要でした）。計算はすべてブラウザ内で完結し、回答が外部へ送信されることはありません。
