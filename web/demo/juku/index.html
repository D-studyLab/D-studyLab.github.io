fukurou learning class

「わかったつもり」を、
置いて帰らせない。

1クラス6人まで。授業の最後に、その日習ったことを先生に「自分の言葉で」説明できたら帰れる塾です。説明できなければ、できるまで付き合います。

小4〜中3・1クラス6人まで・体験2回無料

features

フクロウ塾式、3つのやり方

その一

説明できたら、合格

授業の最後5分は「先生に教え返す」時間。人に説明できて初めて「わかった」です。言葉に詰まったところが、そのまま次回の課題になります。

その二

宿題は塾で終わらせる

授業前後の自習席をいつでも無料開放。家でやれない日があっても大丈夫。わからない問題はその場で質問して、持ち帰らないのがルールです。

その三

順位より、前回の自分

張り出すのは点数ではなく「先月からの伸び」。60点が75点になった子を、90点キープの子と同じだけ褒める教室です。

course

voice

保護者と生徒の声

「今日なにやったの？」に「別に」としか言わなかった息子が、夕飯どきに連立方程式の説明をしてくるようになりました。

中2男子の母

宿題が塾で終わるので、家でのバトルがなくなったのが一番ありがたいです。成績は3ヶ月目から動きました。

小6女子の父

説明タイムは最初いやだったけど、テスト中に「あのとき自分で言ったやつだ」って思い出せる。あれはずるい。
